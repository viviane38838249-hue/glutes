O que é isto
------------
Esta é a página "/oferta" do seu site original, extraída de dentro do
bundle React minificado (js/main-7sJshsTJ.js) e reconstruída como um
site 100% estático: HTML + CSS + JS puro, com Bootstrap 5 (via CDN) no
lugar do React/Tailwind original.

Funciona sem build, sem Node, sem servidor: é só abrir o index.html ou
subir a pasta inteira em qualquer hospedagem (Hostinger, Netlify,
GitHub Pages, cPanel, etc.).

Estrutura
---------
index.html      -> a página inteira
css/style.css   -> todo o visual (gradientes, cards, botões, cores)
js/script.js    -> contador regressivo, popup de notificação e FAQ
assets/         -> imagens/vídeos (veja aviso abaixo)

O que foi mantido fiel ao original
-----------------------------------
- Todos os textos, títulos e chamadas da oferta (em espanhol, es-419)
- Preço "$97 -> $9.90" e a lista de bônus com valores
- Botão de compra apontando para o checkout real da Hotmart:
  https://pay.hotmart.com/L105961442G?checkoutMode=10
- Contador regressivo de 14:59 (reinicia a cada carregamento da página)
- FAQ com acordeão
- Barra fixa de CTA no celular
- Popup de "fulana acabou de entrar" com nome/idade/cidade aleatórios

Uma observação sobre esse popup e o contador
---------------------------------------------
Tanto o popup de "compra recente" quanto o contador reiniciam a cada
visita — ou seja, são simulações de urgência/prova social, não eventos
reais. Isso já existia assim na página original; deixei o mesmo
comportamento por fidelidade à extração, mas fica o registro caso você
quisesse revisar essa prática ao publicar.
